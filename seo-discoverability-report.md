# TutorServices Organic Discoverability Upgrade Report

## Scope
- Audited existing static HTML pages without scanning dependency/build folders.
- Preserved existing URLs, navigation, design system, layout, structured data style and user experience.
- Applied only focused SEO improvements where the current architecture had safe topical gaps.

## Pages Audited
- 82 HTML pages audited.
- Duplicate title tags found: 0.
- Duplicate meta descriptions found: 0.
- Broken internal links found in validation: 0.
- Non-content verification page excluded from normal SEO concern: `google4e98645dcf787467.html`.

## Pages Optimized
- `/` (`index.html`)
  - Updated title and meta description to cover home tutors, private tutors and online tuition more naturally.
  - Added a concise “Choose the right tutor by learning need” section for home tutor, online tuition, one-to-one tutor and location discovery intent.
  - Added internal links to `/home-tuition`, `/online-tuition`, `/one-to-one-tuition` and `/cities`.
- `/boards` (`boards.html`)
  - Expanded natural board coverage from CBSE/ICSE/State Board to include IGCSE, IB and NIOS where tutor availability supports the requirement.
  - Updated title, meta description, OG/Twitter text, Service schema, ItemList schema and FAQ answer text.
  - Added a visible IGCSE/IB/NIOS board-support card without creating thin standalone pages.
- `/classes` (`classes.html`)
  - Aligned class-hub FAQ and related-link wording with CBSE, ICSE/CISCE, IGCSE, IB, NIOS and State Board support.

## New Pages Created
- None. No doorway or thin location/keyword pages were created.

## Keyword Clusters Strengthened
- Core tutor discovery: home tutor, private tutor, online tutor, tutor near me, tuition teacher near me.
- Learning mode discovery: home tuition, online tuition, one-to-one tuition.
- Board tuition: CBSE, ICSE/CISCE, IGCSE, IB, NIOS, State Board.
- Local discovery: tuition by supported locations and online tuition across India.

## Internal Linking Improvements
- Homepage now routes high-intent visitors naturally to the relevant mode/location hubs.
- Board and class hubs now connect broader board intent without excessive linking or duplicate pages.

## FAQ / AEO Improvements
- Board FAQ language now answers broader “which boards are supported” questions directly.
- Homepage includes an answer-first paragraph explaining how to start from class, board, subject, location and mode.

## Structured Data Changes
- Updated `/boards` JSON-LD descriptions to include IGCSE, IB and NIOS.
- Increased `/boards` ItemList from 3 to 6 items, pointing new board entries to the relevant on-page section instead of thin URLs.
- Preserved existing schema types and structure.

## Deliberately Left Unchanged
- Existing indexed URLs and slugs.
- Robots.txt, sitemap and canonicals unless already present.
- Design, global navigation, footer, forms, animations, scripts and styling.
- Verification file `google4e98645dcf787467.html` because it is not a normal SEO landing page.

## Keyword Clusters Rejected for This Phase
- Hundreds of near-me combinations as separate pages.
- Thin city/locality pages without unique local usefulness.
- Exact pricing pages/ranges, because no supported fixed prices were available.
- Fake tutor profiles, reviews, awards, offices or guaranteed outcomes.

## Recommendations for Next Phase
- Continue adding high-quality informational blogs from real parent/student questions.
- Add standalone pages only when there is enough unique, useful content and a distinct search intent.
- Review Search Console queries after indexing to decide future page-level optimizations.
